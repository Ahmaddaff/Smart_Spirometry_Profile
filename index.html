Mengapa Perangkat Ini Dikembangkan?

Poin utama latar belakang dan tujuan pengembangan alat berdasarkan studi kebutuhan kesehatan pernapasan.

Deteksi Dini Penyakit Pernapasan

Penyakit kronis seperti asma dan PPOK sering kali baru terdeteksi pada stadium lanjut. Alat ini dikembangkan sebagai sarana skrining cepat guna mengurangi risiko komplikasi berat sejak awal.

Solusi Spirometri Ekonomis

Spirometer medis standar memiliki harga yang relatif mahal. Menggunakan pendekatan *Water Flow Sensor* yang dikalibrasi, perangkat ini menawarkan biaya produksi jauh lebih rendah tanpa mengorbankan fungsi pengukuran.

Aksesibilitas Faskes Primer

Fasilitas kesehatan tingkat pertama seperti Puskesmas dan unit kesehatan daerah terpencil sering kali belum memiliki spirometer. Alat ini hadir dalam bentuk portabel yang mudah dimobilisasi.

Kemudahan Penggunaan Mandiri

Spirometri konvensional membutuhkan keahlian operator medis khusus. Alat ini memberikan visualisasi indikator zona warna (Merah, Kuning, Hijau) dan nilai kuantitatif yang langsung dipahami oleh masyarakat umum.

Telemetri & Pencatatan Cloud

Mengatasi kelemahan pencatatan manual. Data hasil tiupan secara otomatis terkirim via REST API ke server cloud Vercel dan database Aiven untuk membantu pemantauan riwayat kesehatan secara digital.

Media Pembelajaran IoT Medis

Di samping manfaat medis, alat ini menjadi sarana praktik nyata bagi mahasiswa dan akademisi untuk mempelajari pemrosesan sinyal sensor, integrasi mikrokontroler, dan arsitektur web modern.

Firmware Mechanics & API

Logika Pengukuran & API Payload

Parameter utama yang diproses langsung di dalam mikrokontroler NodeMCU ESP8266.

Parameter Utama Firmware

  • Faktor Kalibrasi Sensor: calibrationFactor = 4.5
  • Faktor Konversi Tekanan: conversionFactor = 0.325
  • Filter Pulsa Inersia: minPulseThreshold = 2
  • Timeout Tiupan Berhenti: blowTimeout = 1500 ms
  • Delay Hold LCD/LED: delay = 5000 ms

Spesifikasi Hardware & Pinout

Pemetaan pin mikrokontroler NodeMCU ESP8266 dengan komponen pendukung.

NodeMCU V3

Unit pemroses utama yang menjalankan skrip C++ & pengiriman data HTTP.

Water Flow Sensor

Terhubung ke Pin D5 dengan mode interrupt pulseCounter.

Sistem Tri-LED

LED Hijau (D6), LED Kuning (D7), dan LED Merah (D8).

LCD Display 16x2

Komunikasi I2C alamat 0x27 untuk menampilkan status real-time.

PANDUAN PENGGUNAAN ALAT

EDUKASI ALAT
1

Persiapan: Posisikan mulut rapat pada corong pipa *Water Flow Sensor* dan tarik napas dalam-dalam.

2

Meniup Kuat: Hembuskan napas sekuat dan sekencang mungkin ke dalam pipa hingga paru-paru terasa kosong.

3

Pembacaan Hasil: Alat akan menangkap laju puncak (*Peak Pressure*), menyalakan indikator LED, dan menampilkan hasil di layar LCD.
